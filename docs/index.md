# 用 TypeScript 编写 HOI4 模组 {#typescript-hoi4}

Krieg 将严格的 `.krg.ts`、`.krg.tsx` 和 `.krg.css` 静态编译为游戏读取的 PDX、GUI、Lua Defines、本地化和资源。编辑器提供类型提示与跳转；源码函数不会被 Node.js 执行。

## 从一个事件开始 {#_1}

第一次使用，直接打开[01：安装并构建](tutorials/first-mod.md)。连续五课从项目安装、中文事件、国策与付费行动推进到 TSX 按钮和原生迁移，每课给出完整文件与输出核对。

## 内容入口与检查层次 {#_3}

常见玩法使用语义 API；人物、科技、装备、AI 等领域使用当前 CWT 快照生成的构造器；需要精确保留重复键与顺序时使用有序 PDX。图片、音频等原生资源按项目规则进入输出。入口和边界见[领域手册](guide/domains/index.md)与[覆盖清单](coverage.md)。

编译、原生结构检查、资源引用检查和游戏运行各自回答不同的问题。构建成功意味着已实现的静态检查通过；触发、显示、刷新和保存/载入仍需在目标游戏中验收。具体解释见[验证层次](guide/validation.md)。

## 当前版本的边界 {#_4}

Krieg 不执行源码中的 JavaScript；网络、文件和任意 npm 运行时代码应放在独立预处理步骤。`any` 与类型逃逸不能绕过语言检查。具体语法见[语言手册](guide/language.md)，提交问题时请附最小复现与实际诊断。
