# Tutorials：从第一个文件到完整玩法

这组教程按步骤完成一件具体的事。01–04 连续使用同一个 `hello-krieg` 项目；05 是独立迁移练习。06 使用同一项目编写可传参数的补给调拨效果。每页都给出完整文件、执行命令和应看到的结果。代码由 `npm run docs:tutorials` 从本页提取，并经过真实项目构建。

| 顺序                                       | 目标                       | 所需资料                     | 完成后得到                       |
| ------------------------------------------ | -------------------------- | ---------------------------- | -------------------------------- |
| [01 安装并构建](first-mod.md)              | 跑通工具和项目             | Node.js 22.17+、npm、Git     | 事件、决议、本地化和可打包的模组 |
| [02 事件与文本](event-and-localisation.md) | 新建一个有中文选项的事件   | 01 的项目                    | `tutorial.1` 和中文 `.yml`       |
| [03 国策与付费行动](focus-and-action.md)   | 国策解锁一次性援助         | 02 的项目                    | 两个国策、共享行动与决议         |
| [04 TSX 界面](action-window.md)            | 按钮复用同一援助           | 03 的项目                    | `.gui` 和匹配的 Scripted GUI     |
| [05 原生脚本迁移](native-port.md)          | 保留重复键并重建脚本       | 已安装的 Krieg；本页原生样本 | 独立的有序 PDX 源工程            |
| [06 调拨补给](typed-allocation.md)         | 用带类型的效果共享调拨规则 | 01 的项目                    | 可在国家作用域调用的库存调拨效果 |

完成练习后，按问题查[领域手册](../guide/index.md)，按名称查[API 与 CLI](../reference/index.md)。要理解真实模组如何组织多个系统，阅读[实际 port 案例](../ports/index.md)。

## 练习的验证范围

教程检查源代码、项目配置、输出路径和关键原生内容。前四课不需要本地游戏文件；第三课的 `GER` 是显式声明的原版引用。要在实际游戏中运行，应配置匹配版本的 `gameRoots`，补齐目标游戏所需资源，再检查加载、显示、触发和读档行为。各层分别证明什么，见[验证手册](../guide/validation.md)。
